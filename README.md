# 🛒 Sistema de Control de Inventarios y Ventas

Aplicación web desarrollada para optimizar la gestión operativa, el registro de ventas en tiempo real y el control financiero de inventarios en negocios comerciales.

---

## 🚀 Características Principales

* **Gestión de Inventario:** Control detallado de stock con actualización automática tras cada venta.
* **Registro de Ventas y Gastos:** Cálculo automatizado de ingresos, costos y márgenes de ganancia por producto.
* **Reportabilidad y Filtros:** Generación de informes financieros filtrables por rangos de fecha y categorías.
* **Exportación de Datos:** Exportación directa de inventarios e informes de ventas a formato Microsoft Excel (`.xlsx`).
* **Base de Datos en Tiempo Real:** Sincronización instantánea de registros y transacciones.

---

## 🛠️ Tecnologías Utilizadas

* **Frontend:** HTML5, CSS3, JavaScript (ES6+)
* **Base de Datos & Backend:** Firebase Realtime Database
* **IA Asistida:** Desarrollo acelerado mediante optimización de código con Claude / ChatGPT
* **Herramientas:** Visual Studio Code, Git
